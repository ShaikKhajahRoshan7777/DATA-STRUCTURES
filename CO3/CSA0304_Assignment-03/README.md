# Data Structures - Assignment 3 (CO3)
### Optimized Data Storage and Retrieval Using Tree-Based Structures  -  SIMATS Engineering

Seven problems, seven trees. Every program is written in C, compiled with `-Wall -Wextra` (most also with AddressSanitizer / UBSan) and run; the output is stored in each folder.

| Folder | Topic | Main programs |
|---|---|---|
| `Q1_BST/` | Binary trees and BST (library catalogue) | `q1_bst_full.c`, `q1_predict_array_tree.c`, `q1_predict_bst_delete.c`, `q1_complete_code.c` |
| `Q2_AVL/` | AVL trees (stock price index) | `q2_avl_full.c`, `q2_complete_code.c` |
| `Q3_BTree/` | B-trees (hospital database on disk) | `q3_btree.c` |
| `Q4_RedBlack/` | Red-black trees (OS scheduler) | `q4_rbtree.c` |
| `Q5_Splay/` | Splay trees (product cache) | `q5_splay.c` |
| `Q6_Trie/` | Tries (phone autocomplete) | `q6_trie_full.c`, `q6_trie_complete.c` |
| `Q7_Dictionary/` | Choosing a tree from first principles (ternary search tree dictionary) | `q7_dictionary.c`, `words_200k.txt`, `sample_1000.txt` |
| `Report/` | Word report + all figures | `Data_Structures_Assignment3_Report.docx`, `figures/` |
| `tools/` | Scripts that regenerate screenshots, figures, the word list and the report | |

Each `Qx/` folder contains the source, `output/` (real program output) and `screenshots/` (VS Code style images of the code and terminal).

## Build and run
```bash
./run_all.sh                 # compile + run everything (about 1 minute; Q2 sorted-BST test ~20 s)
cd Q1_BST && gcc -Wall -Wextra -g -fsanitize=address,undefined q1_bst_full.c -o q1_bst_full && ./q1_bst_full 5
```
Every `.c` file starts with a comment that lists its sections (`./prog 1`, `./prog 2` ...).

## Regenerating screenshots, figures and the report (optional)
```bash
pip install pillow pygments matplotlib
python3 tools/gen_words.py          # synthetic 200,000-word list for Q7
python3 tools/make_screens.py       # runs all programs, writes Qx/output and Qx/screenshots
python3 tools/make_figures.py       # tree diagrams and charts -> Report/figures
NODE_PATH=$(npm root -g) node tools/build_report.js   # needs the `docx` npm package
```

## Notes
* **Screenshots** are VS Code (Dark+) style renderings generated by `tools/make_screens.py`: the code is the real source file and the terminal text is the real output of compiling and running it. Take native VS Code screenshots if your course requires them - the commands are shown in each image.
* **Q7 data:** the assignment gives no word list, so `tools/gen_words.py` generates 200,000 synthetic Tamil-style words. Replace `words_200k.txt` with a real dictionary to repeat the experiment.
* Timings were measured on a single-core Linux container; ratios matter more than absolute values.
* The "Complete the Code" programs mark the finished parts with `TODO n (completed)` comments.
